# ایده‌هاب (Idea Hub)

نسخه نمایشی (MVP) سامانه داخلی جمع‌آوری و اولویت‌بندی ایده‌های کارکنان. این پروژه یک اپلیکیشن تک‌صفحه‌ای (SPA) کاملاً فارسی و راست‌چین است که **بدون بک‌اند، بدون پایگاه‌داده و بدون احراز هویت** ساخته شده و تمام داده‌ها را در `localStorage` مرورگر ذخیره می‌کند. هدف آن، نمایش تجربه ثبت، مشاهده و اولویت‌بندی ایده‌ها به مدیران و همکاران است، نه استفاده در محیط عملیاتی واقعی.

## امکانات

### نقش «همکار»
- مشاهده، جست‌وجو و فیلتر ایده‌ها (بر اساس حوزه و وضعیت)
- مشاهده تب‌های «جدید»، «پررأی» و «منتخب»
- ثبت ایده جدید
- رأی‌دادن به ایده‌ها
- مشاهده جزئیات و وضعیت هر ایده
- مشاهده ایده‌های ثبت‌شده توسط خودش («ایده‌های من»)

### نقش «ارزیاب»
- مشاهده صف بررسی (ایده‌های نیازمند اقدام)
- درخواست تکمیل اطلاعات از پیشنهاددهنده
- امتیازدهی به ایده بر اساس ۴ معیار وزن‌دار
- تغییر وضعیت ایده همراه با ثبت دلیل تصمیم

نقش نمایشی و نام کاربر از بالای صفحه (هدر) قابل تغییر است تا بتوان هر دو تجربه را در یک دمو نشان داد.

## معیارهای اولویت‌بندی

| معیار | وزن |
|---|---|
| اهمیت مسئله | ۳۵٪ |
| هم‌راستایی استراتژیک | ۳۰٪ |
| کیفیت شواهد | ۲۰٪ |
| سهولت اجرا | ۱۵٪ |

امتیاز نهایی هر ایده از میانگین وزنی این چهار معیار (هرکدام از ۱ تا ۵) محاسبه می‌شود.

## وضعیت‌های ایده

ثبت‌شده ← نیازمند تکمیل ← در حال بررسی ← کاندید بررسی بیشتر ← (فعلاً در برنامه نیست | وارد برنامه شد ← اجرا شد)

## فناوری

- React + TypeScript
- Vite
- React Router (`HashRouter`، سازگار با انتشار استاتیک روی GitHub Pages)
- Vitest + React Testing Library برای تست
- ذخیره‌سازی کامل در `localStorage` (بدون هیچ سرویس یا کلید بیرونی)

## اجرا در محیط توسعه

```bash
npm install
npm run dev
```

سپس آدرس نمایش‌داده‌شده در ترمینال (معمولاً `http://localhost:5173/idea-hub/`) را در مرورگر باز کنید.

## اجرای تست‌ها

```bash
npm test
```

## ساخت نسخه نهایی (Build)

```bash
npm run build
```

خروجی در پوشه `dist/` تولید می‌شود. برای پیش‌نمایش خروجی build به‌صورت محلی:

```bash
npm run preview
```

## انتشار روی GitHub Pages

این مخزن شامل یک workflow آماده در مسیر `.github/workflows/deploy.yml` است که با هر push به شاخه `main`، به‌صورت خودکار تست‌ها را اجرا کرده، پروژه را build می‌کند و در GitHub Pages منتشر می‌سازد.

برای فعال‌سازی (فقط یک‌بار لازم است):

1. به تنظیمات مخزن در گیت‌هاب بروید: **Settings → Pages**
2. در قسمت **Build and deployment → Source**، گزینه **GitHub Actions** را انتخاب کنید.
3. یک بار به شاخه `main` push کنید (یا workflow را به‌صورت دستی از تب **Actions** اجرا کنید).

آدرس نهایی سایت به‌صورت `https://<نام‌کاربری>.github.io/idea-hub/` خواهد بود.

> توجه: تنظیم `base: '/idea-hub/'` در `vite.config.ts` از قبل با نام همین مخزن هماهنگ شده است. اگر مخزن را با نام دیگری فورک یا کپی کردید، این مقدار را متناسب با نام مخزن جدید تغییر دهید.

## ساختار پروژه

```
src/
  components/   کامپوننت‌های رابط کاربری (layout, idea, form, evaluator)
  context/      مدیریت وضعیت سراسری (ایده‌ها، نقش، نام کاربر) + همگام‌سازی با localStorage
  data/         داده‌های نمونه و ثابت‌ها (حوزه‌ها، وضعیت‌ها، وزن معیارها)
  hooks/        هوک‌های مشترک (useLocalStorage)
  pages/        صفحات اصلی برنامه
  styles/       استایل‌های سراسری و متغیرهای طراحی (RTL)
  types/        تعریف تایپ‌های TypeScript
  utils/        منطق محاسبه امتیاز، فیلتر/جست‌وجو و قالب‌بندی تاریخ
```

## محدودیت‌های شناخته‌شده (به‌عنوان یک MVP نمایشی)

- داده‌ها فقط در مرورگر همان کاربر ذخیره می‌شوند؛ بین چند کاربر یا دستگاه همگام‌سازی نمی‌شوند.
- هیچ احراز هویتی وجود ندارد؛ «نام شما» صرفاً برای شبیه‌سازی هویت در دمو استفاده می‌شود.
- برای پاک کردن کامل داده‌های دمو، کافی است localStorage مرورگر برای این آدرس را پاک کنید.
